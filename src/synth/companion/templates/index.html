How this chat uses LangfusePYTHON · PROMPT EXAMPLE

Fetch the production prompt, then fill in its variables for each reply. This simplified example uses the Product explainer.

import json
from langfuse import get_client

# Server-side: credentials come from environment variables.
langfuse = get_client()

# Resolve the version labelled production, including its text blocks.
prompt = langfuse.get_prompt(
    "products/explainer",
    type="chat",
    label="production",
    cache_ttl_seconds=0,
)

# Shortened example data; the app supplies the full product record.
reference_context = {"product": "Everyday Account", "monthly_fee_eur": 4}
conversation_history = []  # Previous user/assistant messages; empty on turn one.
user_message = "What is the monthly fee?"

messages = prompt.compile(
    reference_context=json.dumps(reference_context, ensure_ascii=False),
    conversation_history=conversation_history,
    user_message=user_message,
)
# messages now contains the system instructions, history and user question.
# Pass these compiled messages to the model to generate a reply.
{{reference_context}}
Product facts retrieved by the app, inserted as text.
conversation_history
A message placeholder filled with earlier user and assistant turns.
{{user_message}}
The current question, inserted into the user message.

This companion disables prompt caching so a production promotion takes effect on the next request. Referenced text building blocks are resolved by Langfuse; they are separate from the variables passed to compile(). Retrieval and compilation happen on the server, so API keys stay out of the browser.
